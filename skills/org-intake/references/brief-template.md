# brief.md Template

Use this template when generating the organization brief. Replace bracketed placeholders with actual information from the intake session.

```markdown
# Organization Brief

**Generated:** [current date]

## Organization
- **Name:** [name]
- **Website:** [url]
- **Description:** [1-3 sentence description]

## Mission & Focus
[Mission / theory of change as described by the user. Keep their language but tighten for clarity.]

## Online Presence

| Platform | Handle / URL | Status |
|----------|-------------|--------|
| Website | [url] | Active |
| YouTube | [handle or URL] | [Active/Inactive/Unknown] |
| Substack | [handle or URL] | [Active/Inactive/Unknown] |
| ... | ... | ... |

## Key Audiences
[Bulleted list of audience segments]

## Team & Capacity
- **Team size:** [number or range]
- **Communications capacity:** [description]
- **Approximate annual comms budget:** [amount or range]

## Current Strategy & Goals
[Summary of any existing strategy, or "No formal strategy in place" if none]

## Audit Goals
[What the user hopes to learn or achieve from the audit]

## Additional Context
[Any other relevant information the user provided, or "None provided"]
```

## Notes

- All fields except Name and Website are optional. If the user skipped a section, either omit it or write "Not provided".
- For the Online Presence table, include only platforms that were discovered or mentioned. Mark status as Active, Inactive, or Unknown based on what the user confirmed.
- Keep the user's own language where possible — don't rephrase their mission statement into corporate-speak.
